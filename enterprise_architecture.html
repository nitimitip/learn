How this view is built what the boxes and the lines mean

Every active application is placed in the Application Category recorded on its record — the business area it serves — so this view cuts across delivery towers rather than following them. Applications with no category collect under Uncategorised, which is a gap in the data rather than a business area.

Connections come from each application's External Interfaces, resolved exactly as the Tower View resolves them: an interface whose host matches a server listed under another application's Infrastructure resolves by hostname, failing that an interface naming another application resolves by name, and anything left over is an external system. Both views read the same graph, so they can never disagree about what is connected to what.
