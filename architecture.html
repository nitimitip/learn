How connections are resolved what the lines on this diagram mean

Connections come from each application's External Interfaces. An interface whose host matches a server listed under another application's Infrastructure resolves to that application by hostname; failing that, an interface naming another application resolves by name. Anything left over is an external system and is listed above, labelled with the Application name the Utility module's server inventory records against its hostname — or with its own interface name when the host is not in that inventory either.
